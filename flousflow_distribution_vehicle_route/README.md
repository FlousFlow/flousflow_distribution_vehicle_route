## Overview

See the module description in `__manifest__.py` and the views inside the module.
This module is part of a suite — install its dependencies first.

## Installation

1. Add this repository to your Odoo `addons_path`.
2. Update the apps list and install the module.
3. Dependencies install automatically from the Odoo Community store.
